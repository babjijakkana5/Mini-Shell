# Mini Shell in C

## Overview
Mini Shell is a command-line shell developed using C. The project demonstrates fundamental operating system concepts, process management, command execution, and signal handling.

## Features
- Execute external commands using `fork()` and `execvp()`
- Support built-in commands such as `cd`, `pwd`, and `exit`
- Support command pipelines using pipes
- Handle signals such as `SIGINT`, `SIGTSTP`, and `SIGCHLD`
- Implement basic job management using `jobs`, `fg`, and `bg`
- Support a customizable command prompt
- Use ANSI escape codes for colored terminal output

## Technologies Used
- C Programming
- Linux/POSIX system calls
- Process management
- Signal handling
- Pipes and file descriptors
- Linked lists

## Project Structure

- `main.c` — Main shell loop and command processing
- `builtin.c` — Built-in command implementation
- `external.c` — External command execution and pipeline handling
- `signal.c` — Signal handling and job management
- `minishell.h` — Shared declarations, macros, and data structures
- `mini.txt` — External command list
- `Makefile` — Build configuration

## Build and Run

```bash
make
./minishell
```

Use the executable name generated by your Makefile if it differs from `minishell`.
